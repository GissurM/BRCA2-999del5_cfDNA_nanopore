Extracts information on a cfDNA threads chromosome of origin using positional data chromosome_histogram.py can be ran directly on the bam files. Run chromosome_counts.R and then chr_statistics.py on the output in order to receive more complex results.

## Dependencies
- R version 4.5.0 (This version is tested others may work just as well)
  - Rsamtools (v2.18.0)
  - ggplot2 (v4.0.2)
- Python (v3.9+)
  - numpy (v2.0.2)
  - pandas (v2.2.3)
  - scipy (v1.13.1)
  - matplotlib (v3.9.1)
